# 모두의 매크로 (modu_auto)

코딩 없이 **누구나, 어떤 모바일 게임이든** 매크로를 만들 수 있는 PC 프로그램.
**[● 녹화]를 켜고 평소처럼 한 번 플레이하면 매크로가 만들어진다.**

- 안드로이드 실기기 / PC 에뮬레이터(LDPlayer, 블루스택, MuMu, 녹스) 지원 (adb)
- 터치한 버튼을 자동으로 잘라서 등록하고, 잘 찾을 수 있는 이미지인지 🟢🟡🔴로 바로 알려줌
- 해상도가 다른 기기에서도 자동 보정
- 매크로 = 폴더 하나 (`macro.json` + `templates/*.png`) → 폴더째 공유하면 다른 사람도 그대로 사용

## 설치

1. Python 3.10+ 설치
2. `setup.bat` 실행 (가상환경 + 패키지 + scrcpy/adb 자동 다운로드)
3. `run.bat` 실행 → 기기가 없으면 **기기 연결 도우미**가 자동으로 열림 (USB / 에뮬레이터 / 무선 안내)

## 3분 만에 매크로 만들기

1. **🔌 기기 연결** → 초록색 "연결됨"이 뜨면 완료
2. **● 녹화 (F9)** → 매크로 이름 확인 (Enter)
3. 왼쪽 화면에서 **평소처럼 게임을 터치**
   - 클릭 = 탭, 드래그 = 스와이프, 꾹 누르기 = 길게 누르기
   - 터치는 폰에 그대로 전달되고, 누른 버튼이 이미지로 등록되면서 스텝이 자동으로 쌓임
   - 툴바의 **◀ 뒤로 / ⌂ 홈**도 녹화됨
4. 다시 **● 녹화**를 눌러 끝 → **전체 반복** 횟수 정하고 **▶ 실행** (F8 = 정지)

### 녹화가 똑똑하게 해주는 것

- **버튼 자동 인식**: 누른 곳의 버튼 테두리를 찾아 버튼 전체를 자른다. 글자 위를 눌러도 된다.
- **품질 신호등**: 🟢 좋음 / 🟡 주의(비슷한 게 또 있음, 너무 작음) / 🔴 나쁨(단색, 너무 큼). 마우스를 올리면 이유가 나온다.
- **닮은꼴 대응**: 비슷한 버튼이 있으면 일치도 기준을 자동으로 올리고, 완전히 똑같은 버튼이 여러 개면 **녹화한 자리에서 가장 가까운 것**을 누른다.
- **자동 대기**: "찾아서 탭"은 버튼이 나타날 때까지 최대 10초 기다리므로 로딩 시간을 따로 넣을 필요가 없다.
- **이름 자동**: 이미지1, 이미지2… (F2로 이름 변경)

## 직접 편집하기 (편집 모드)

녹화를 끄면 편집 모드다.
- 화면 **드래그** → 이미지 등록 + "찾아서 탭 / 나타날 때까지 대기 / 사라질 때까지 대기" 스텝 (드래그하는 동안 돋보기 표시)
- 화면 **클릭** → 그 좌표로 탭, 길게 누르기, 스와이프 스텝
- **📺 실시간 보기**: 폰 화면을 계속 갱신 / **화면 캡처 (F5)**: 한 장만
- 스텝 더블클릭 = 편집, 드래그 = 순서 변경, Delete = 삭제
- 이미지 더블클릭 = 현재 화면에서 매칭 테스트

### 스텝 종류

| 메뉴 | 스텝 | 설명 |
|---|---|---|
| 이미지 | 찾아서 탭 / 나타날 때까지 대기 / 사라질 때까지 대기 | 최대 N초 동안 찾는다 |
| 터치 | 좌표 탭 / 길게 누르기 / 스와이프 | |
| 기타 | 대기, 버튼(뒤로/홈 등), 글자 입력(영문) | |
| 끝내기 | **이번 회차 끝** | 남은 스텝을 건너뛰고 다음 반복으로 |
| | **완전 정지** | 매크로 전체 종료 |
| 고급 | 있으면 분기, 라벨, 라벨로 이동 | 조건 분기, 부분 반복 |

이미지를 끝내 못 찾으면 → **완전 정지 / 이번 회차 끝 / 무시하고 다음 스텝 / 라벨로 이동** 중에서 고를 수 있다.

**실행 설정**: 스텝 간 대기, 랜덤 지연, 탭 위치 흔들림, 이미지 재확인 간격
