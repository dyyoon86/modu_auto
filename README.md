# 모두의 매크로 (modu_auto)

코딩 없이 **누구나, 어떤 모바일 게임이든** 매크로를 만들 수 있는 PC 프로그램.
폰 화면에서 버튼을 드래그로 잘라 등록하고, "이 이미지가 보이면 탭 / 기다리기 / 분기 / 반복" 스텝을 쌓으면 끝.

- 안드로이드 실기기 또는 에뮬레이터 (adb 연결)
- 화면 인식: OpenCV 템플릿 매칭, **해상도가 다른 기기에서도 자동 보정**
- scrcpy 미러링 창으로 폰을 PC에서 보면서 조작
- 매크로 = 폴더 하나 (`macro.json` + `templates/*.png`) → 폴더째 공유하면 다른 사람도 그대로 사용

## 설치

1. Python 3.10+ 설치
2. `setup.bat` 실행 (가상환경 생성 + 패키지 설치 + scrcpy/adb 자동 다운로드)
3. 폰: 설정 → 휴대전화 정보 → 빌드번호 7번 탭 → 개발자 옵션 → **USB 디버깅 ON** → USB 연결 후 "허용"
4. `run.bat` 실행

## 사용법

1. 상단에서 기기 선택 → **화면 캡처 (F5)**
2. **새 매크로** 로 이름 지정
3. 캡처 화면에서
   - **드래그** → 버튼 이미지 저장 + "찾아서 탭 / 나타날 때까지 대기 / 있으면 분기" 스텝 추가
   - **클릭** → 그 좌표 탭, 길게 누르기, 스와이프 스텝 추가
4. 반복하려면 맨 위에 `라벨`, 맨 아래에 `라벨로 이동` 스텝을 넣는다
5. **▶ 실행** (F8 = 정지). 실행 중엔 화면에 찾은 위치가 초록 박스로 표시됨

### 스텝 종류

| 분류 | 스텝 | 설명 |
|---|---|---|
| 이미지 | 이미지 찾아서 탭 | 최대 N초 동안 찾고, 찾으면 가운데(+보정)를 탭 |
| | 나타날 때까지 대기 / 사라질 때까지 대기 | 로딩, 연출 끝나길 기다릴 때 |
| | 있으면 분기 | 있으면 라벨 A로, 없으면 라벨 B로 |
| 터치 | 좌표 탭 / 길게 누르기 / 스와이프 | |
| 기타 | 대기, 버튼(뒤로/홈 등), 글자 입력(영문) | |
| 흐름 | 라벨, 라벨로 이동(N회/무한), 종료 | |

이미지 스텝은 "끝내 못 찾으면" → 정지 / 다음 스텝 / 특정 라벨로 이동 중 선택.

### 팁

- 템플릿은 **버튼 글자나 아이콘만 작게** 자르는 게 잘 잡힌다 (배경이 바뀌는 부분은 빼기)
- 템플릿 더블클릭 = 현재 화면에서 매칭 테스트 (일치도 확인)
- 안 잡히면 일치도를 0.75~0.8로 낮추거나 다시 자르기
- **실행 설정**에서 스텝 간 대기, 랜덤 지연, 탭 좌표 흔들림 조절

## 주의

대부분의 게임은 약관상 매크로 사용을 금지하고 있어서 계정 제재를 받을 수 있다. 사용 책임은 사용자에게 있다.
